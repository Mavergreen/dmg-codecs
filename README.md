# DMG Codecs for Mavericks

Compressed-disk-image codecs (LZFSE, LZMA) for Mac OS X 10.9 Mavericks.

If you see "corrupt image" when trying to mount a `.dmg`, you need these.

Add [linuxfs](https://github.com/Mavergreen/linuxfs) and you'll even be able to mount APFS disk images.

## Usage

Double-click `.dmg` as usual, except more of them work now.
(Or `hdiutil attach` as usual, if that's your thing.)
